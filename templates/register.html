What happens when you register?

  • Your file is uploaded securely over localhost.
  • Its SHA-256 hash is calculated on the server from the actual bytes.
  • The filename, file size, hash, and timestamp are saved in SQLite.
  • The uploaded file is deleted immediately after hashing.
  • A unique Record ID is assigned — use it during verification.
